# Seth Greenan — Artist Portfolio

A dark, premium single-page artist portfolio built with Vue 3, TypeScript, Vite and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
npm run preview
```

## Main sections

- Home / hero
- Featured artwork
- About Seth
- Pricing / commission guide
- Contact
- Instagram + email only

## Customise

Edit `src/App.vue` to change the artwork titles, prices, email address and Instagram URL.

The generated visual reference is stored at `src/assets/site-reference.png` and is used as the hero artwork/background.
